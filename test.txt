=== MCP Remote Go - Transport Test Suite ===

This file contains test commands for all transport methods.
Copy and paste the JSON lines (NOT the echo commands) into the running bridge.

================================================================================
TEST 1: Legacy SSE Transport (HTTP+SSE 2024-11-05)
================================================================================

Start bridge:
go run main.go --url=https://mcp.example.com/sse --header "X-Api-Key: clp_sk_1a2b3c4d5e6f7g8h9i0j" --debug

Paste these lines one by one (press ENTER after each):

1. Initialize:
{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2024-11-05","capabilities":{},"clientInfo":{"name":"mcp-remote-go","version":"1.0.0"}}}

2. Initialized notification (wait for response from step 1 first):
{"jsonrpc":"2.0","method":"notifications/initialized"}

3. List tools:
{"jsonrpc":"2.0","id":2,"method":"tools/list","params":{}}

4. List resources:
{"jsonrpc":"2.0","id":3,"method":"resources/list","params":{}}

5. List prompts:
{"jsonrpc":"2.0","id":4,"method":"prompts/list","params":{}}
