================================================================================
TROUBLESHOOTING
================================================================================

Issue: "Could not parse message"
Solution: Make sure you're NOT typing "echo" - just paste the JSON directly

Issue: "Invalid request parameters"
Solution: Must send "initialize" first before any other requests

Issue: "Authentication required"
Solution: Check your API key/token in --header flag

Issue: "HTTP 405 Method Not Allowed"
Solution: Server doesn't support that transport, try different strategy

Issue: Bridge connects but no response
Solution: Check if you need to send "notifications/initialized" after initialize
